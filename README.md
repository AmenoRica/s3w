# 스플래툰 3 무기 데이터베이스

**기본 실행 환경은 [GitHub Pages 공개 사이트](https://amenorica.github.io/splatoon3-weapon-browser/)입니다.**
로컬 확인은 아래의 HTTP 서버를 사용하세요. 스테이지는 모듈·데이터 요청을 사용하므로 HTML 파일 직접 열기를 기본 실행 방식으로 사용하지 않습니다.
HTML·CSS·일반 JavaScript로 만든 정적 페이지입니다. npm 설치나 빌드가 필요하지 않습니다.
게임 데이터·이미지·글꼴은 포함되어 있습니다. 관련 공략 목록은 Google Sheets에서 가져옵니다.

## 기능

- 대전용 주무기 174개: 일반 무기와 대전에서 사용할 수 있는 레플리카 포함
- 이름·서브·스페셜 검색, 무기 종류 필터, 이름·필요 SP·해금 랭크 정렬
- 이미지, 서브·스페셜 조합, 필요 SP, 일반 해금 랭크
- 부키치 설명: 전용 원문이 있는 159개 무기, 각 지역 언어 원문 사용
- 게임 내 성능 지표와 원본에 명시된 상세 수치
- 무기별 전체 원본 파라미터 펼치기 및 출처 링크
- 상세 수치 아래 메인·서브·스페셜 관련 공략 목록
- 버전 옆 주사위: 시드로 재현할 수 있는 랜덤 정렬, 4개씩 번호가 붙은 묶음
- URL의 `#lang=KRko&weapon=Shooter_Normal_00` 등으로 언어·무기 지정
- 검색·필터·정렬 상태도 주소에 저장. 언어 설정은 가능한 경우 기기에 저장
- 작은 화면 대응, 키보드 탐색, Escape로 상세창 닫기

11개 언어·문자권, 지역 변형 포함 14개 코드:
한국어, 일본어, 영어(미국/유럽), 독일어, 스페인어(스페인/아메리카),
프랑스어(유럽/캐나다), 이탈리아어, 네덜란드어, 러시아어, 중국어 간체/번체.
게임 명칭과 설명은 원본 번역이며, 검색·정렬 등 이 페이지의 UI 문구는 별도로 번역했습니다.

## 랜덤 무기

버전 표시 옆 주사위를 누르면 검색·종류 필터를 해제하고 대상 무기를 새 시드로 섞습니다.
주소의 `#rand=시드&lang=KRko`를 공유하면 같은 데이터 버전에서 같은 순서와 묶음을 볼 수 있습니다.
언어와 화면 크기를 바꿔도 순서는 유지됩니다. 넓은 화면은 한 묶음에 4열, 좁은 화면은 2열 2행으로 표시합니다.
해금 랭크가 없는 무기는 새싹 슈터만 포함합니다. 현재 대상은 160개, 총 40묶음입니다.
주사위를 다시 누르면 새 시드가 만들어집니다. 초기화하거나 검색·종류·일반 정렬을 변경하면 랜덤 모드가 종료됩니다.
새 시드는 `a478`처럼 16진수 4자리입니다. 기존의 긴 시드 주소도 계속 사용할 수 있습니다.
팀 번호 옆의 작은 `복사` 버튼을 누르면 팀 번호, 무기 4개 이름, 해당 팀으로 이동하는 `#rand=a478&lang=KRko&team=3` 형식의 링크가 복사됩니다.
파일을 직접 열어 복사해도 공유 링크는 공개 사이트 주소를 사용합니다.

## 공략 추가·수정

[공략 편집 시트](https://docs.google.com/spreadsheets/d/13fsuFudKMveXRW7Yvfpro8rGrVCTe24Nf4t9A4fg5h4/edit)를 엽니다.

1. `메인`, `서브`, `스페셜` 중 해당 탭을 고릅니다.
2. 표의 빈 행에서 **무기**를 드롭다운으로 선택하고 **제목**, **링크**를 입력합니다.
3. 같은 무기에 공략을 여러 개 넣으려면 같은 무기를 다시 선택하고 새 제목·링크를 입력합니다. 한 공략을 여러 무기에 연결하려면 첫 행에 제목·링크를 넣고 아래 행에는 무기만 선택합니다. 표 아래에 행을 추가하면 드롭다운도 이어집니다.
4. 웹페이지를 새로고침합니다. Google 쪽 반영까지 잠시 걸릴 수 있습니다.

메인 탭의 **무기** 칸에 개별 무기 이름을 넣으면 해당 무기 세트에만 표시됩니다. `롤러`, `스피너`처럼 한국어 무기군 이름을 넣으면 해당 무기군 전체의 메인 공략에 표시됩니다. 개별 무기 공략과 무기군 공략은 시트의 행 순서대로 함께 표시됩니다. 서브·스페셜은 해당 장비를 사용하는 모든 무기에 공통으로 표시됩니다.
모든 페이지 언어에서 같은 공략 목록을 보여주며, 제목은 입력한 그대로 표시합니다.
시트의 위에서 아래 순서로 표시합니다. 빈 제목과 링크는 **각각 가장 가까운 위쪽의 값**을 이어받습니다. 탭 사이에서는 이어받지 않습니다. 중간의 빈 행은 이어받기를 끊지 않습니다.
위에도 값이 없거나, 이어받은 링크가 올바른 `https://`·`http://` 주소가 아니면 해당 행은 표시하지 않습니다.
무기가 빈 행은 표시하지 않습니다. 연결을 제거하려면 무기 칸을 비우세요. 공략 묶음을 지우려면 제목·링크가 있는 첫 행과 이를 이어받는 무기 행을 함께 지우세요.
제목이나 링크만 지우면 위쪽 공략을 이어받으므로 삭제 용도로 사용하지 마세요. 정렬하면 이어받는 관계도 달라지므로 공략 묶음의 행 순서를 유지해 주세요.
시트 탭 이름과 열 순서(`A: 무기`, `B: 제목`, `C: 링크`)는 유지해 주세요. 첫 행은 머리글로 사용합니다.

시트는 **링크가 있는 모든 사용자 · 뷰어**로 공유합니다. 편집 권한은 별도로 유지됩니다.
읽기 방식은 [Google의 공개 스프레드시트 안내](https://developers.google.com/chart/interactive/docs/spreadsheets)를 따릅니다.
API 키·별도 서버·라이브러리 설치는 필요 없습니다. 다른 시트로 바꾸려면 `guides.js`의 `sheetId`를 바꿉니다.
파일을 직접 열면 Google의 [JSONP 응답 방식](https://developers.google.com/chart/interactive/docs/dev/implementing_data_source)을 사용합니다. 웹서버에서 열면 `fetch`로 읽습니다.
각 목록은 처음 상세창을 열 때 가져오며, 시트를 읽을 수 없으면 해당 목록에 다시 열기 버튼을 표시합니다.

## 데이터와 단위

기준: **11.3.0 (`1130`)**. 최신 버전을 자동으로 따라가지 않습니다.

- 원본 저장소: https://github.com/Leanny/splat3
- 고정 커밋: `7280ff9cde8bb1c5dcef46c700c326471584d2e6`
- `data/mush/1130/WeaponInfoMain.json`: 대전 무기 목록·조합·SP·랭크·게임 성능 표시
- `data/language/*_full_unicode.json`: 무기명·종류·부키치 이름과 전용 대사
- `data/parameter/1130/weapon/*.game__GameParameterTable.json`: 무기별 상세 수치
- `images/weapon_flat`, `images/subspe`, `images/npc`: 게임 이미지
- `sources.json`: 수집 기준, 원문 개수와 생성 데이터 해시

게임 성능 막대는 **0–100의 상대 지표**이며 실제 대미지·거리 단위가 아닙니다.
`WeaponInfoMain.Range`는 원본 저장소의 데이터베이스에서도 **Matchmaking Range**로
분류하는 매칭용 값입니다. 실측 유효 사거리로 표시하지 않습니다.
차저의 탄 이동 거리처럼 명시된 거리값은 내부 단위라고 표시합니다.

대미지는 원본값 ÷ 10으로 100 HP 기준, 잉크 소비는 원본값 × 100으로 탱크 비율,
프레임은 원본값과 60프레임/초 기준 환산값을 표시합니다.
와이퍼의 근접 판정·탄, 스트링거의 화살·폭발, 셸터의 산탄 상한 등은 따로 표시합니다.
기어 효과, 감쇠, 여러 탄의 명중, 충전 방식 등을 합산한 최종 실전 성능은 아닙니다.

**원본에 없는 값을 기본값으로 추정하지 않습니다.** 따라서 무기마다 상세 항목의 수가
다릅니다. 예를 들어 스플랫 슈터의 원본 성능 파일은 일부 기본 타이밍을 생략합니다.
전체 파라미터는 상세창 하단에서 확인할 수 있습니다.

일부 셸터 변형 7개는 지정된 개별 `SpecActor` 파일이 저장소에 없습니다.
이때 `MatchingId`로 연결되는 기본 무기의 파일을 참고로 제공하고,
상세창에 **기본 무기 참고값** 및 해당 기본 무기 이름을 명시합니다.
이는 해당 변형의 모든 성능이 동일하다고 단정하는 처리가 아닙니다.
전용 설명이 없는 15개 무기는 다른 무기 대사로 대체하지 않습니다.

## GitHub Pages 배포

`.github/workflows/pages.yml`이 `main` 푸시 또는 수동 실행 시 검증 → 배포 파일 조립 → GitHub Pages 배포를 수행합니다. PR에서는 검증과 조립까지만 실행합니다. 저장소 Pages의 Source는 **GitHub Actions**를 사용합니다.

```sh
python3 tools/build-pages.py
node tools/verify-pages.mjs
```

배포에는 `_site/`만 사용합니다. 런타임 코드, 무기 이미지·글꼴, 스테이지 썸네일과 manifest가 참조하는 지형만 포함합니다. 기존 렌더러의 대체 지형도 유지합니다. `outputs/`, `map-demo/`, `planner-demo/`, `tools/`, 문서와 Git 메타데이터는 포함하지 않습니다. 원본 폴더와 실험 결과는 삭제하지 않습니다.

현재 배포 묶음은 576개 파일, 약 156 MB입니다. JS·CSS·JSON 참조는 콘텐츠 기반의 공통 릴리스 식별자로 갱신합니다. GitHub Pages 프로젝트 하위 경로에서도 동작하도록 상대 경로를 유지합니다. 압축 지형은 일반 `.bin.gz` 파일로 제공하며 별도 `Content-Encoding` 설정을 추가하지 않습니다.

CI는 실험 결과가 필요한 `verify-minimaps.mjs`를 제외한 동작 검증과 배포 결과물 검증을 실행합니다. 로컬 정밀 비교는 `node tools/verify-minimaps.mjs`로 별도 실행합니다. 배포 검증은 39개 스테이지·167개 조합, 지형 디코딩, 파일 참조와 캐시 버전, 개발 파일 제외를 확인합니다.

## 로컬 미리보기

선택 사항입니다. 터미널에서 이 폴더로 이동한 후:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8765 를 여세요.
검증은 이 방식으로 수행했습니다. 브라우저 자동화 도구의 파일 URL 접근 제한으로
`file://` 직접 열기는 자동 검증 대상에서 제외했습니다. 공략 연결은 파일 실행과 같은 `Origin: null` 환경에서 실제 Google Sheets 응답을 받아 별도로 검증했습니다.

## 같은 기준으로 데이터 다시 받기

Python 3의 기본 라이브러리만 사용합니다.

```sh
python3 update-data.py
```

일반 이용자는 실행할 필요가 없습니다. 스크립트의 `COMMIT`과 `VERSION`을 바꾸면
다른 스냅샷을 수집할 수 있지만, 새 데이터의 구조·누락 파일·수치 단위를 다시 검토해야 합니다.
원본 응답은 운영체제 임시 폴더에 캐시됩니다. 다운로드에 실패하면 스크립트가 오류를 내고
완성되지 않은 새 `data.js`로 기존 데이터를 덮어쓰지 않습니다.

## 파일 구성

- `index.html`, `style.css`, `tokens.css`: 화면과 디자인
- `app.js`: 검색·언어 전환·상세창
- `ui.js`: 페이지 조작 문구 11개 번역
- `guides.js`: Google Sheets 공략 읽기 및 링크 검증
- `random.js`: 시드 기반 무기 섞기와 랜덤 대상 제한
- `data.js`: 원본에서 추출한 게임 데이터
- `assets/`: 로컬 이미지·글꼴
- `update-data.py`: 원본 수집 및 추출
- `sources.json`, `verification.json`: 데이터 기준과 검증 기록

디자인에 [Nutlope/Hallmark](https://github.com/Nutlope/hallmark)를 적용했습니다.
Catalogue 구성, Brutal의 굵은 선과 제목, Splatoon을 연상시키는 잉크색·라임 포인트를 사용합니다.
글꼴 Bricolage Grotesque는 Google Fonts 저장소에서 받았고,
라이선스는 `assets/FONT-LICENSE.txt`에 포함되어 있습니다. 한글 등은 기기의 글꼴로 표시합니다.

비공식 팬 페이지입니다. 게임 이미지와 원문은 Nintendo에 권리가 있습니다.

## 스테이지 뷰어

상단 **스테이지** 탭에서 소개 이미지·이름 목록과 회전 가능한 3D 지도를 열 수 있습니다. 대전 25개(5개 룰), 연어런 7개 및 빅 런 7개(간조·일반·만조)를 포함합니다. 트리컬러는 제외합니다. 지형은 v11.2.0 추출본이며, 선택한 맵과 룰만 내려받습니다. 용량·표시 한계·추출 및 검증 절차는 [stages/README.md](stages/README.md)를 참고하세요.

스테이지 아래의 **마커 링크 복사**는 현재 맵·룰과 마커 위치, 방향, 배경색, 기어 AP, 샤크라이드 출발점을 링크에 담습니다. 링크를 열면 배치를 복원합니다. 복사 뒤 수정한 배치는 새 링크를 복사해야 반영됩니다. 카메라 상태는 저장하지 않습니다.

공유 링크는 좌표를 0.01 단위의 signed int16, 방향을 한 바퀴의 1/256 단위로 저장합니다. 링크 내부의 무기 키 목록을 참조하고 기본 설정은 생략합니다. 바이너리 v2와 gzip으로 더 짧아진 경우의 v3를 지원하며, 이전 JSON v1 링크도 읽습니다. 압축은 링크 생성 시에만 적용하고 현재 화면의 좌표는 바꾸지 않습니다. 지형 경계에 정확히 걸친 배치는 반올림으로 가림 판정이 달라질 수 있습니다.
