# 기어 파워 계산기

## 승인된 기능 계약

2026-09-21: 이전 대화의 독립 로컬 프로토타입 구성을 이어받아, 사용자가 조건부 기어의 **발동 토글과 단계 직접 선택**, **에너지 스탠드 토글**을 요청했다. 최대 발동으로 고정하는 안은 채택하지 않는다.

무기와 머리·옷·신발의 큰 슬롯 각 1개, 작은 슬롯 각 3개를 고르면 메인·서브·스페셜·이동·슈퍼 점프 결과를 즉시 갱신한다. 탄퍼짐은 숫자와 각도 그림으로, 이동은 연습장 4칸을 왕복하는 이모지로, 점프는 차지와 비행을 구분한 왕복 그림으로 보여준다. 사용자가 비워 둔 메인 3번 항목은 추가하지 않는다.

첫 화면은 스플랫 슈터, 빈 기어, 조건 미발동으로 시작한다. 선택은 화면 수명 동안만 유지한다. 무기·스테이지와 공통 상단바를 사용하며 `gear/`를 세 번째 탭으로 배포한다. 기존 11개 언어·14개 지역을 지원한다. 공식 이름은 `gear-names.json`, UI 번역은 `messages.json`에서 읽으며 언어 전환은 조합을 초기화하지 않는다.

추가 요청: 슬롯을 원형으로 만들고 팔레트에서 끌어 장착한다. 터치·키보드 대안은 팔레트 선택 후 슬롯 선택이다. 빈 슬롯 도구로 해제하며 장착 부위 제한을 동일하게 검증한다. 드래그 대상과 팔레트 선택은 UI 전용 임시 상태다.

사용자는 잉크 회복 시각화를 **잠복 중만 표시**하도록 선택했다. `InkRecoverFrm_Stealth`의 원본 곡선과 현재 잉크 회복력 업 AP, 탱크 용량으로 빈 탱크가 가득 차는 시간을 계산한다. 기어 없는 탱크와 현재 탱크를 동시에 채운다. 공격 직후 회복 대기는 제외하며 회복 개시 시점부터 표시한다. 이 시간과 채움 비율은 저장하지 않는 파생값이다.

추가 승인: 이동 비교는 느린 쪽까지 왕복을 마쳐야 함께 재출발한다. 징어닌자 미장착 시 잉크 튐을 표시한다. 액션 강화의 징어클라임은 원본 플레이어 `WallJumpChargeFrm` 곡선으로 충전 시간을 비교한다. 슈퍼 점프 차지에 떨림, 착지에 1초 인간 상태 대기를 추가한다. 스텔스 점프 장착 시에만 거리 슬라이더를 표시한다. 범위는 60단위 이하–100단위 이상이며 기본 위치는 100단위 이상이다. 사용자가 지정한 선형 가정에 따라 0–60프레임을 계산하고 정수 프레임으로 올림한다. 무기와 기어 슬롯만 링크에 저장하며 발동 조건과 애니메이션 진행은 저장하지 않는다.

사용자는 평지·고정 각도 투척 근사와 서브·스페셜 지속시간 숫자 표시를 승인했다. 거리·폭발 범위는 비교 막대, 투척은 모션을 함께 표시한다. 잉크 회복·징어클라임·슈퍼 점프 애니메이션은 유지한다.

AP 합산(큰 슬롯 10, 작은 슬롯 3), 장착 부위 제한, 상한 57, 곡선 보간, 단위 환산과 반올림은 순수 계산 규칙이다. 게임의 조정 수치는 출처가 있는 읽기 전용 스냅샷이며 이 사이트에서 게임 밸런스를 편집하지 않으므로 전용 데이터 에디터는 필요 없다. 무작위 연산, 저장 마이그레이션, 외부 계정·서버·새 패키지 의존성도 없다.

## 계산과 경계

- 게임 데이터 버전은 기존 사이트와 같은 11.3.0이다. 생략된 엔진 기본값은 검증된 별도 출처가 있는 값만 사용한다. 확인 불가는 `미확인`, 해당 동작이 없는 경우는 `해당 없음`으로 구분한다.
- AP는 장착값과 조건 적용 후 값을 구분한다. 장착하지 않은 조건부 기어는 발동할 수 없다. 라스트 스퍼트는 단계 선택을 제공한다. 단계가 없는 조건부 효과는 켜짐·꺼짐만 제공한다.
- 에너지 스탠드의 이동 속도 효과는 현재 AP와 비교하며, 상한에 도달한 항목은 더 가산하지 않는다. 자신의 스페셜이 에너지 스탠드가 아니어도 버프를 선택할 수 있다.
- 공격 횟수는 잉크 회복 없이 한 통으로 정상 소비량을 온전히 지불할 수 있는 횟수다. 스피너는 풀 차지 횟수, 차저·스트링거·와이퍼는 완전 차지와 일반 공격을 구분한다. 잉크 부족 상태에서 가능한 약화 공격과 무기별 시간 경과 회복은 계산하지 않는다. 새싹 계열의 큰 탱크를 반영한다.
- 사망 손실은 사망 직전 보유 SP에 대한 비율이다. 적의 기어·상대 리벤지 등 선택되지 않은 외부 조건은 포함하지 않는다.
- 이동은 정상 지면에서의 최고 속도이며 가속·감속은 제외한다. 내부 거리 5단위가 연습장 1칸, 60프레임이 1초다.
- 스텔스 점프 추가 비행 시간은 `ceil((거리−60)/40×60)`으로 근사한다. 60단위 이하에서 0, 100단위 이상에서 60프레임이다. 선형 보간은 사용자 지정 가정이며 실제 게임의 보간식으로 단정하지 않는다. 선택 거리는 UI 상태, 추가 시간은 파생값이며 미장착 시 0이다.
- 서브 투척 초기 속도를 사거리라고 바꾸어 부르지 않는다. 검증된 범위·지속 시간·내구도 등 실제 강화되는 항목을 표시한다.
- 원본이 기본 무기 참고값을 사용하는 변형 무기는 결과에도 같은 제한을 표시한다.

## 출처와 재현

- `data.json`: Leanny/splat3 커밋 `7280ff9cde8bb1c5dcef46c700c326471584d2e6`, 게임 버전 1130. 공통 곡선은 `data/parameter/1130/misc/params.json`, 부위 제한은 `spl__GearSkillTraitsParam`, 기어 한국어 명칭은 원본 언어 파일에서 가져온다.
- `icons/`: 같은 커밋의 `images/skill/`에서 가져온 기어 이미지. 게임 이미지와 명칭의 권리는 Nintendo에 있다.
- 조건 중첩과 원본 파일이 생략한 엔진 기본값은 [sendou.ink 고정 커밋](https://github.com/sendou-ink/sendou.ink/tree/7e95ae2eb3fd8ca8857372566c79e9937cb5e8f2/app/features/build-analyzer)과 대조했다. sendou UI나 모듈을 복사하거나 실행 의존성으로 추가하지 않았다.
- 보간은 [Leanny 기어 분석](https://leanny.github.io/splat3/ability.html)에 명시된 수학식과 원본 곡선이다. 이동 단위와 와이퍼·롤러·브러시 예외는 [이동 기어 검증](https://wikiwiki.jp/splatoon3mix/ギア/ギアパワー/分割2), [무기별 이동 표](https://wikiwiki.jp/splatoon3mix/ブキ)와 대조했다.
- 출처가 다른 값은 생성 도구의 `defaults`, `conditions`, `rules`에서 분리해 둔다. 실행 중 외부 데이터를 가져오거나 게임 수치를 편집하지 않는다.

## 거리 미리보기 모델

- 일반 투척은 출발·착지 동일 높이, 정지한 투척자 기준이다. 위쪽 조준 각도 0–90도를 0.5도 간격으로 전수 탐색하고 최적 구간을 0.01도 간격으로 세분화하여 첫 착지 수평 거리를 최대화한다. 초기 수평·상향 속도 벡터를 함께 회전한다. 원본 초기 수평·상향 속도로 1프레임씩 위치를 누적하고 공기저항·중력을 적용해 첫 동일 높이 교차점을 구한다. 원본에 생략된 중력 0.016/저항 0.05866은 **미리보기용 공통 가정**이며 확인된 엔진 기본값으로 주장하지 않는다. 추적·바운드·구르기는 제외한다. 실측 사거리가 아닌 해당 근사 모델의 최대 거리다.
- 라인 마커는 원본 비행 7프레임 동안의 직선 이동, 컬링은 기존 스테이지 뷰어에 출처가 기록된 무차지 평지 약 6.9칸에 초기 속도 비율을 적용한다.
- 모델 설정은 읽기 전용 스냅샷의 `throwModel`, 궤적·거리·증가량은 순수 파생값이다. 곡선의 액션 강화 징어클라임 충전은 `SplPlayer.spl__PlayerGearSkillParam_ActionSpecUp_Squid`의 Low/Mid/High 45/18/5를 사용한다.

- 174개 무기·696개 시나리오와 투척 궤적의 유한성·착지·증가 방향을 검사했다. 라인 마커 8.82→9.52칸, 컬링 근사 6.9→8.97칸의 양 끝값을 확인했다. 스텔스 0/1/30/60프레임, 미장착 시 무효, 징어클라임 0/10/57 AP에서 45/25/5프레임을 확인했다.

추가 UI 요청: 징어클라임의 기본·현재 이모지도 각자 충전하는 동안 좌우 흔들림을 표시한다. 충전 완료 때 흔들림을 멈춘 뒤 상승하며, 전체 일시정지와 공통 반복 주기를 따른다. 계산 데이터 변화는 없다.

## 서브 영향 감소 시각화 (2026-09-21 승인)

상대 서브 드롭다운은 자신의 무기 세트와 독립이며 기본은 스플래시 밤이다. 폭발은 공통 범위 그림 하나와 거리별 기본/현재 피해 계단 그래프 및 숫자, 마킹은 함께 시작해 감소하는 지속시간 게이지로 비교한다. 트랩처럼 복합 효과가 있는 서브는 둘 다 표시한다. 컬링은 최소/최대 차지, 탄산은 각 폭발, 토피도는 본체/작은 폭발을 각각 명시한다. 피해는 단일 폭발 기준이며 지형·높이·복수 폭발 합산은 하지 않는다.

상대 서브 성능 업이 방어 결과에 반영되는 트랩·포인트 센서·라인 마커에 0–57 AP 슬라이더를 표시한다. 기본과 현재 비교 양쪽에 같은 상대 AP를 적용한다. UI 상태 `enemySub`와 `enemySubAP`는 새로고침 때 초기화하며 공유 링크에 넣지 않는다. 현재 기어 AP를 읽고, 고정 원본에서 수집한 피해 거리와 감소 곡선을 `data.json`에 추가한다. 피해·범위·시간은 `core.js`가 재계산하는 파생값으로 저장하지 않는다. 새 서버·의존성·랜덤·저장 마이그레이션은 없다.

포이즌 미스트의 `MoveDownRt_PoisonMist` 곡선은 확인되었으나 기본 이동 감소율은 원본에 생략되어 있다. 아래 사용자 제공 단계별 모델을 사용한다.

추가 승인: 사용자가 제공한 표와 스크린샷에 따라 포이즌 미스트 둔화 레벨을 선택한다. 레벨 1/2/3의 인간 속도 배율은 0.65/0.43/0.20, 스윔 배율은 0.55/0.32/0.10이며 진입 후 시간 표시는 0/1.3/2.6초다. 이 표는 확인된 엔진 파라미터가 아닌 사용자 제공 모델로 출처를 분리해 `defense.PoisonMist.mistLevels`에 기록한다. 기존의 일괄 50% 감속 가정은 채택하지 않는다. `mistLevel`은 기본 1의 UI 상태로 저장하지 않는다. 선택 단계는 고정되며 시간에 따른 자동 레벨 변경은 하지 않는다. 방어 적용 배율은 `1 - (1 - 단계별 기본 속도 배율) × MoveDownRt_PoisonMist(AP)`이다. 인간 이동과 징어대시의 기본/현재 속도에 각각 적용하며 기존 왕복 애니메이션을 재사용한다. 상대 서브 성능 업은 미스트 둔화 계산에 관여하지 않아 슬라이더를 숨긴다.

## 잉크 효율 테스트 (2026-09-21 승인)

메인·서브 잉크 효율 영역의 `테스트`로 현재 무기·기어를 가져오는 대화상자를 연다. 메인 버튼을 누르는 동안 확인된 발사 간격으로 사용하며 스피너는 누르는 동안 차지하고 놓으면 발사한다. 복수 공격은 선택한다. 서브 버튼은 한 번당 1회 사용한다. 자연 회복은 없으며, 채우기 버튼을 누르는 동안 현재 기어와 탱크의 잠복 회복 시간으로 잉크를 채운다. 버튼을 놓으면 멈추고 공격 횟수는 유지한다. 회복 대기는 기존 회복 시각화와 같이 제외한다. 게이지에 서브 1회 소비량 선을 표시하며 조작 안내 두 줄은 표시하지 않는다.

정본은 기존 `data.js` 무기 파라미터와 `core.js` 기어 적용 계산 결과다. 테스트의 잉크(0–100%), 차지, 발사 진행, 사용 횟수는 대화상자 수명 동안만 존재한다. 선택·정본·공유 링크를 수정하지 않는다. 타이밍이 미확인인 공격은 임의 간격을 넣지 않고 수동 1회 사용으로 표시한다. 잉크 부족 약화 공격은 기존 계산기와 같이 제외한다. 스피너는 승인된 1차지/풀 차지만 발사하며 단계 사이 보간을 하지 않는다. 차저는 차지 없이/풀 차지, 스트링거는 차지 없이/1차지/풀 차지를 선택한다. 스트링거 1차지 소비량은 원본 InkConsumeMidCharge에 기존 기어 보정 비율을 적용한다. 메인 발사 테스트 버튼은 상자 접힘 여부와 무관하게 제목 줄의 무기 아이콘 왼쪽에 표시한다. 서브 테스트 버튼은 펼친 내용 안에 둔다. 서브 소비 기준선에 보이는 글자 라벨은 없다.

입력 명령 → 확인된 무기 값과 현재 기어 계산 결과 → 임시 상태 변경 → 탱크·차지·사용 횟수 표시 순서다. 새 밸런스 정본·무작위·저장·에디터는 없다. 닫기/포커스 이탈/모드 전환 시 입력을 해제하고 예약된 발사를 정리한다. 구현 후 소비량·잉크 경계·차지/발사 전이 자동 검사와 데스크톱/모바일 브라우저 조작을 확인한다.

테스트 타이밍의 보충값은 [스플랫 슈터](https://wikiwiki.jp/splatoon3mix/ブキ/スプラシューター)의 6F와 [스플랫 차저](https://wikiwiki.jp/splatoon3mix/ブキ/スプラチャージャー)의 60F다. 기존 원본에서 생략된 해당 기본 무기 값만 보충한다. 게임 수치 편집 기능이 아닌 읽기 전용 보충값이므로 데이터 에디터는 필요하지 않다. 스피너 완료 단계의 장탄 수는 floor(사격 지속 프레임 / 연사 간격)+1이며 1차지 소비는 풀차지 소비에 장탄 수 비율을 적용한다. 미니·하이드라·이그재미너의 공개 검증 표와 대조했다. 쿠겔 슈라이버·휴는 [검증 위키의 v11.0 측정 표](https://wikiwiki.jp/splatoon3mix/ブキ/クーゲルシュライバー)를 보충 출처로 사용한다. 1차지는 50F·23발·12.78%(출처의 반올림 값), 풀차지는 100F·45발·25%다. 두 단계 모두 첫 10발은 3F, 이후 전환탄을 포함한 나머지는 5F 간격이며, 1차지 소비량에도 기존 메인 잉크 효율 보정 비율을 적용한다. 1차지 사격 종료 프레임은 위키 실측 92F와 단순 간격 합산 사이 1F 차이가 있어 전환 시점의 정확한 재현은 보장하지 않는다. 재차지/차지 킵, 이동·피해·탄도와 부분 충전 잉크 선차감은 범위에 포함하지 않는다.
